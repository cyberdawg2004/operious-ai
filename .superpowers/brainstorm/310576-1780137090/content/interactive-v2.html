Security Architecture

Five containment layers. None optional.

The gap between what an AI model proposes and what it is permitted to execute is not a policy. It is architecture.

01
ToolInvoker Enforcement
LLM output is a proposal, not a command. Every action passes through ToolInvoker before execution. The model cannot bypass it.
02
Governance Substrate
Policy chains evaluate every proposed action. Empty chains return DENY. There is no path to ALLOW without a passing policy.
03
Row-Level Security
Enforced at the database layer on every tenant-scoped table. No query reaches data it isn't authorized to see, regardless of model instruction.
04
UUID5 Cryptographic Identity
Every decision, agent, and execution carries a deterministic fingerprint. Replayable. Forensically reconstructible from any point in time.
05
Append-Only Timelines
No event can be modified after creation. The audit trail is immutable by architecture — not by policy — and cannot be silently corrupted.
