Security Architecture

Five containment layers. None optional.

The separation between what a model proposes and what it is permitted to execute is not a policy. It is architecture.

01
ToolInvoker Enforcement
LLM output is a proposal. Every action passes through ToolInvoker. The model cannot bypass it.
02
Governance Substrate
Policy chains evaluate every action. Empty chains return DENY. No implicit allow.
03
Row-Level Security
Enforced at database layer on every tenant table. No query escapes its scope.
04
UUID5 Cryptographic Identity
Every decision carries a deterministic fingerprint. Replayable from any checkpoint.
05
Append-Only Timelines
No event can be modified. Immutable by architecture, not by policy.
