Security Architecture

Five containment layers. None optional.

The separation between what a model proposes and what it is permitted to execute is not a policy choice. It is architecture.

01
ToolInvoker Enforcement
Every LLM output is a proposal, not a command. Actions pass through ToolInvoker before execution. The model cannot bypass it.
02
Governance Substrate
Policy chains evaluate every proposed action. Empty chains return DENY. There is no path to ALLOW without a passing policy.
03
Row-Level Security
Enforced at the database layer. No query reaches data it is not authorized to see, regardless of what the model instructs.
04
UUID5 Cryptographic Identity
Every decision, agent, and execution is deterministically fingerprinted. Replayable. Forensically reconstructible from any point in time.
05
Append-Only Timelines
No event can be modified after creation. The audit trail is immutable by architecture — not by policy — and cannot be silently corrupted.
