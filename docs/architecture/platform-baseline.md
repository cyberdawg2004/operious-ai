# Operious Platform Baseline

- Next.js 14.2.35
- React 18.3.1
- TailwindCSS 3.4.19
- Framer Motion 11.x
- Zustand
- React Query
- React Flow

## Backend Foundation Stack

- Python 3.12
- FastAPI
- SQLAlchemy Async
- PostgreSQL
- Deterministic substrate architecture

## Architectural Rules

- No uncontrolled runtime mutation
- No implicit orchestration
- No hidden retries
- No dynamic runtime planning
- Translation occurs at the boundary
- Governance precedes execution
- Memory evolves asynchronously
- Runtime execution remains replayable
